# 账号解析器

解析工作台导出的「账号 + AT」或「邮箱凭证 + AT」文本，并生成两个一一对应的 txt 文件。

| 输入模式 | 文件 1 | 文件 2 |
|---|---|---|
| 账号 + AT | `邮箱-密码-2FA.txt`：`邮箱----密码----2FA密钥` | `AT.txt`：`AT` |
| 邮箱凭证 + AT | `邮箱凭证.txt`：完整邮箱凭证（原样保留） | `AT.txt`：`AT` |

两个文件的**行顺序一一对应**：文件 1 的第 1 行，对应文件 2 的第 1 行。

如有格式错误，页面还会显示第三个下载项 `解析失败原始行.txt`，每条失败输入原样占一行，方便修正后重试。

如果格式选错，工具会识别工作台免密 AT 导出的邮箱凭证结构，立即提示切换对应格式并停止本次解析；不会显示下载结果，也不会把邮箱凭证错误地解析成账密数据。

如果整段内容没有任何一条符合两种支持格式，工具同样会显示红色提示并停止，不会生成空的下载结果。若输入中同时含有成功和失败行，则成功行照常解析，失败行会进入 `解析失败原始行.txt`。

## 怎么用

1. 打开网页
2. 选择与工作台导出内容相符的格式
3. 把 txt 拖进去（或直接粘贴内容）
4. 点「开始解析」
5. 分别点两个「下载」按钮，得到两个 txt 文件

**所有内容都只在浏览器本地处理，不会上传到任何服务器**，可以断网使用。

## 离线使用

整个工具就是一个 `index.html` 文件，没有任何外部依赖：

- 打开页面后「右键 → 另存为」，保存到本地，双击即可使用
- 或者直接下载本仓库的 `index.html`

## 支持的输入情况

### 账号 + AT

解析时是**从行尾往左剥离**的（先认 AT，再认 2FA，剩下的按第一个分隔符切成邮箱和密码），所以下面这些情况都能正确处理：

| 情况 | 示例 |
|---|---|
| 标准四段 | `a@b.com----Pw123456----JB...32位----eyJ...` |
| 密码以 `-` 结尾 | `a@b.com----Pw1234------eyJ...` |
| 密码中间含 `-` | `a@b.com----ab-cd-ef----JB...----eyJ...` |
| 密码含连续 `-` | `a@b.com----ab----cd----JB...----eyJ...` |
| 没有 2FA 的三段 | `a@b.com----Pw123456----eyJ...` |
| 空行 / `#` 注释行 | 自动忽略 |

工作台导出的 AT 是以 `eyJ` 开头、由 3 段组成的 JWT。AT 前必须有 `----` 分隔符；缺少 AT、AT 格式不对，或 2FA 与 AT 粘连的行都会报错，不会被误拆成结果。

### 邮箱凭证 + AT

输入为 **`完整邮箱凭证----AT`**。邮箱凭证内部沿用工作台原格式
`邮箱----邮箱密码----client_id----refresh_token`；其中 `refresh_token` 即使包含 `----` 也会原样保留，工具只剥离最右侧的 AT。

**任何解析不了的行都会如实报错并指出行号**，不会悄悄丢掉，避免数据静默丢失。

## 常见问题

**格式错误的行怎么办？**
格式错误的行不会写入两个正常结果文件；页面会列出原始行号和失败原因，并提供 `解析失败原始行.txt` 下载。该文件只保留原始输入、一行一条，方便修正后重新处理。

**“空行 / 注释”是什么意思？**
只统计输入中间的空白行，或以 `#`、`/` 开头的注释行；它们不会参与解析，也不会写入结果。文本末尾的换行不会计入。

**AT 是什么？**
访问令牌（access token）。某些第三方工具只需要 AT，不需要邮箱密码，所以拆开更方便。

**会泄露我的账号吗？**
不会。页面没有任何后端，也不发任何网络请求，全部计算在你自己电脑的浏览器里完成。你可以断网验证。
